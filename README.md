## ▶️ How to Run

1. Install [Python 3.x](https://www.python.org/downloads/)
2. Clone the repository
   ```bash
   git clone https://github.com/aditigaikwad8/python-learning-journey.git
   cd python-learning-journey
   ```
3. Run any program
   ```bash
   python "Strings and Conditional Statements/10.P6_Largest_of_4.py"
   ```
